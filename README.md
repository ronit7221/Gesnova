GesNova - ISL Gesture Recognition System

GesNova is a real-time Indian Sign Language (ISL) recognition system that uses a hybrid approach combining MediaPipe landmark extraction and deep learning. The system detects hand gestures through a webcam and converts them into readable and audible output.

---

 Features

- Real-time gesture recognition using webcam
- MediaPipe-based hand landmark extraction
- Deep learning model for classification
- Web-based interface using Flask
- Confidence-based prediction display
- Speech output for detected gestures

---

 System Architecture

Webcam → MediaPipe → Landmark Extraction → Deep Learning Model → Prediction → Web UI → Speech Output

---

🖥️ Tech Stack

- Python
- TensorFlow / Keras
- OpenCV
- MediaPipe
- Flask (Backend)
- HTML, CSS, JavaScript (Frontend)
